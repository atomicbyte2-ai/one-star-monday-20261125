# One Star for Monday

> One star. Seated by the alarm clock, served cold coffee, and charged for the whole weekend.

A one-star review of Monday, written as if Monday were a restaurant: the diner gets the worst table (next to the alarm clock), a cold dish (cold coffee), and a bill for the whole weekend. `main.ts` holds the line as a constant, validates it (1–180 characters, at most 25 words, single line, no control characters), then writes it as `entry.txt` — with no trailing newline — to `MAKEFUN_OUTPUT_DIR` (default `/output`).
